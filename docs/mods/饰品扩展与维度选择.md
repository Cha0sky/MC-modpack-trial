# 饰品扩展与维度选择

适用开发版为 Minecraft 1.21.1、NeoForge 21.1.248。主线装备手册的「全饰品 · 从材料追到成品」目录有四个模组入口。材料页和进阶页也可直接打开。

| 分册 | 版本 | 可佩戴条目 | 怎么用这册 |
|---|---|---:|---|
| 神秘遗物 Enigmatic Legacy+ | 1.21.1-1.1.2 | 69 | 从七咒之戒看穿戴代价和救赎路线，从非欧立方回查候选术石。保留两个已注册的占位卷轴，页内注明状态。[发行页](https://modrinth.com/mod/enigmaticlegacy-plus/version/ELK5gx91) |
| Relics | 0.10.7.8 | 24 | 按单件查对应箱子与群系，再在背包中研究遗物、解锁能力。另收四件手持遗物。叶环在此版没有默认生存来源。[发行页](https://modrinth.com/mod/relics-mod/version/nvZZMhJS) |
| 星月遗物 Celestial Artifacts | 2.0.4 | 92 | 查传家项链、套装、灾厄之册和刻蚀板，沿配方追到星月核心材料。特殊击杀条件随对应物品说明。[发行页](https://www.curseforge.com/minecraft/mc-mods/celestial-artifacts/files/8805750) |
| Baubley Heart Canisters | 1.21.1-1.4.2 | 6 | 查生命护符、灵魂生命护符及四色腰带。护符右击装罐后佩戴，每罐增加 2 点最大生命。普通护符四种颜色默认各装十罐，灵魂护符另有第五色。[发行页](https://modrinth.com/mod/baubley-heart-canisters/version/C8wXuovY) |

**非欧立方**需要寰宇之心、十种合格术石中任选六种且各不相同、24 份术石残片。术石台另设核心槽，取出成品还会消耗一枚术质核心。任务图的线列出可选材料，实际数量与取得条件以成品页为准。

**生命护符**的额外生命由佩戴生效。灵魂护符的专用升级配方保留已装心罐。把护符进一步用作剑或弓的合成材料前，先取出罐子。

图鉴共 691 件饰品、450 件盔甲，四色心罐、术质核心、星月材料和手持遗物等另设 57 页。部署前用加载器采用的 JarJarSelector 和 Maven 版本规则核对了新增文件与现有依赖。星月核心带入的旧版 L2Library 由实例原有的独立 3.0.8 满足。游戏中的掉落、装填、额外生命与 HUD 仍待实测。

## 持有记录与救赎之戒

从任务栏点装备图标可查看 JEI 配方。队伍中任一成员首次持有即可登记，背包、快捷栏、副手、盔甲栏和已装备的 Curios 槽都能检测。取得成品时可以直接点亮它，配方连线仍用于查看材料和去向。目录页可以手动标记已读。旧版空任务的完成记录会在队伍数据下次加载时按新条件校正。

救赎之戒从零阶继承七咒之戒的正面效果和专属物品使用资格，卷轴按七条固有诅咒计数。抢夺、时运与救赎自身加成取较高值。需要额外佩戴时长的深渊遗物保留各自条件，佩戴救赎之戒也可累计时长。

兼容模组源代码在 `modules/pack-compat`。用仓库既有 Wrapper 编译，可用 `-PpackMods=...` 指定开发实例的 mods 目录。

```powershell
.\modules\world-progression-core\gradlew.bat -p modules/pack-compat build
python tools/deploy_equipment_collection.py
```

部署器按任务 ID 更新实例中已有的任务页，同时安装兼容 JAR。授权部署时追加 `--apply`。

## 重建任务书

七个固定发行文件、版本、下载地址见 [版本清单](gear-expansion.lock.json)。在仓库根目录运行：

```powershell
python tools/deploy_gear_expansion.py --prepare-only
$gearMods = 'work/gear-expansion-20261123/payload/mods'
python tools/build_accessory_catalog.py --extra-mods $gearMods
python tools/build_armor_catalog.py --extra-mods $gearMods
python tools/build_gear_guide.py --extra-mods $gearMods
python tools/deploy_gear_expansion.py
```

最后一条会列出将要更新的文件。经授权部署时用同一命令加 `--apply`；旧文件备份和本次新增文件清单写入部署回执，便于整体回退。
