# 星庭远征 · 饰品与装备扩展候选

核对日期为 2026-11-23。当前开发版为 Minecraft 1.21.1、NeoForge 21.1.248。下列是候选，兼容性依据为作者发行页及所列版本文件，整包游玩兼容性待选定后验证。

## 非欧立方

**非欧立方**出自《神秘遗物》Enigmatic Legacy。原作者的中英文语言文件将 `enigmaticlegacy:the_cube` 分别命名为「非欧立方」和 *Non-Euclidean Cube*。在本包的平台上能选 **Enigmatic Legacy+**，对应 ID 改为 `enigmaticlegacyplus:the_cube`。已查移植版 1.21.1-1.1.2 发布 JAR 的语言文件、物品标签和实际配方。[原作者中文语言文件](https://github.com/Aizistral-Studios/Enigmatic-Legacy/blob/1.20.X/src/main/resources/assets/enigmaticlegacy/lang/zh_cn.json) · [1.21.1 NeoForge 移植版](https://modrinth.com/mod/enigmaticlegacy-plus/version/ELK5gx91)

移植版的术石台配方要求 **1 颗寰宇之心、6 件互不相同的合格术石、24 份术石残片**。该版本的材料标签有 10 个候选，因此可以给玩家留出选哪六条收集路线的自由。它还有跨维度随机传送能力。很适合做成前线站交班后的收藏终点，让各路首领的战利品逐渐汇到同一张合成图上。[项目说明与版本](https://modrinth.com/mod/enigmaticlegacy-plus)

## 大型或体系化扩展

| 候选与核准版本 | 实际提供的内容 | 在本包的取舍 |
|---|---|---|
| **Celestial Artifacts 2.0.4** | 作者列出 84 种饰品，从早期工具性效果到后期战斗装备，配有传家项链和灾厄卷轴 | **优先考虑增加合成树时选它。** 能与现有饰品图按流派组织。开局物品、卷轴诅咒和恶意词条一并启用前，需要确定想让玩家承担哪些负面效果。[作者及 1.21.1 NeoForge 发行](https://www.curseforge.com/minecraft/mc-mods/celestial-artifacts) |
| **Enigmatic Legacy+ 1.21.1-1.1.2** | 术石、戒指、强力遗物与高阶合成，包含非欧立方 | **优先考虑毕业目标时选它。** 适合接非强制的长线收藏，优先核对飞行、减伤和传送对场地战的影响。该 JAR 声明 NeoForge ≥21.1.224。[发行文件](https://modrinth.com/mod/enigmaticlegacy-plus/version/ELK5gx91) |
| **Relics 0.10.7.8** | 有主动或被动机制的探索遗物，通过使用、养成提升同一件装备 | **优先考虑让遗迹值得再去时选它。** 可把装配和实战练习接到已有远征。该版要求 Curios 和 OctoLib ≥0.6.0.1，实例已有 Curios，还需补 OctoLib。[作者项目](https://modrinth.com/mod/relics-mod) · [发行文件](https://modrinth.com/mod/relics-mod/version/nvZZMhJS) |
| **Epic Knights 10.17** | 中世纪护甲、马铠、盾牌、不同触及距离与用途的武器 | **优先考虑补武器和盔甲时选它。** 钢材加工适合接工坊，长兵器、重甲和盾牌能给同一档首领提供另一套打法。发行 JAR 要求的 Architectury 与 Cloth Config 已在实例中。[作者项目](https://modrinth.com/mod/epic-knights-shields-armor-and-weapons) · [发行文件](https://modrinth.com/mod/epic-knights-shields-armor-and-weapons/version/Pzhaw0LB) |
| **Apotheosis 8.9.0（神化）** | 装备词缀、稀有度、宝石镶嵌与世界层级 | 适合想把反复刷装备作为后期玩法时选择。它会同时改变装备强度与遭遇难度，和现有莱特兰的重合度最高。该版本需要 Placebo ≥9.9.2、Apothic Attributes ≥2.10.0。[作者项目](https://modrinth.com/mod/apotheosis/) · [发行文件](https://modrinth.com/mod/apotheosis/version/veL1ccTb) |
