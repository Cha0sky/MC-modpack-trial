# 星庭远征 · 首领分档与战斗分组

这份设计给每场战斗两个标记。**档位**回答“什么样的队伍可以第一次去试”，**打法**回答“进场后最值得留心什么”。默认是一名首次接战的生存玩家，Minecraft 普通难度、汇流经典模式，使用该阶段正常取得的装备、饰品和补给。保留本实例的莱特兰配置。同档内可自由选对手，具体档位仍待实机校准。

## 六档首战

| 档位 | 推荐时机与准备 | 归入本档的战斗 |
|---|---|---|
| Ⅰ · 开荒 | 序章至第一章。基础护甲、回复食物、一段能横移的平地即可尝试 | **史莱姆王**、克苏鲁之眼、育母蜘蛛 |
| Ⅱ · 专项挑战 | 第一至二章。备好一种惯用武器，再配位移、清群或抗异常中的一项 | 钢铁守护者、世界吞噬怪、克苏鲁之脑、骷髅领主、巫婆、飓风 |
| Ⅲ · 世界转折 | 第二章的高难自选至第三章。能处理连续攻势和阶段变化，有补给，也有撤退路线 | 霜冻巨兽、蜂王、骷髅王、独眼巨鹿、太阳鸟·乌姆武提、异教牧首、灾厄教父、孤魂尸鬼、凋灵死灵法师、**血肉墙／血肉山** |
| Ⅳ · 遗址远征 | 第四至五章的配装水平。能持续输出和回复，包里有处理飞行目标或清援的第二种手段 | 普通死者之王、灾厄宰相、凋灵、末影龙、末影遣使 |
| Ⅴ · 后期讨伐 | 第五至六章可先发现地点，准备成熟后接战。一套能持续作战的装备，再补足对手要求的机动、抗性或近身输出 | 末影守望者、末影守卫、远古遗魂、下界合金巨兽、斯库拉、提洛斯回响·原初受火者、不祥死者之王、默认切磋的星之魔女 |
| Ⅵ · 毕业挑战 | 当前主线终点后的自由悬赏。按具体对手准备一套打法，能处理限伤、转阶段和失手后的恢复 | 先驱者、利维坦、咒翼灵骸、焰魔、使徒。档内建议先试先驱者，焰魔和使徒压轴，下界使徒最后 |

Ⅰ至Ⅲ档允许真实的难度梯度。第二章现有六选一正好能作示例：克苏鲁之眼适合先过调查，钢铁守护者适合愿意练读招的人，霜冻巨兽留给想试较难战斗的人。世界吞噬怪、克苏鲁之脑和骷髅领主给擅长清群或切目标的玩家。调查结算仍是工程、奥术、远征三线任选二。[第二章现有委托](heritage-survey.md)

Ⅳ档里的末影龙和凋灵各有自己的原版入口。章位只表示推荐战力。第五章现有正式悬赏为普通死者之王和灾厄宰相，勘察手记、照片、回访制图也能结章。[第五章现有委托](relic-expeditions.md)

## 按首要打法分组

每位首领在下表有一个主组。括号里的处理方式可作为副标签，让同档的两张委托玩起来有明显区别。

| 主组 | 对手 | 玩家应做的事 |
|---|---|---|
| 闪避与追击 | 史莱姆王、克苏鲁之眼、蜂王、霜冻巨兽、远古遗魂 | 等跳扑或冲锋方向确定后横移，落点或冲锋终点才是反打窗口。蜂王留在丛林应战并兼顾小蜂，霜冻巨兽要留出躲冰息的侧向空间。远古遗魂冲锋带生命比例伤害，换位比硬吃更划算。 |
| 读招与破防 | 钢铁守护者、飓风、独眼巨鹿、末影遣使、末影守卫、焰魔 | 钢铁守护者重斧卡地后绕背。飓风会弹箭，应换输出方式。独眼巨鹿要进到约 20 格内才有可靠的攻击机会。焰魔还要求在盾牌、连斩和抓取之间判断什么时候收手。 |
| 部位与目标顺序 | 世界吞噬怪、克苏鲁之脑、骷髅领主、骷髅王、末影龙 | 吞噬怪可以打多段，但打断会增加独立行动的虫体。克脑先清视神经元，骷髅领主先拆骨身，骷髅王断双手后头部失甲。末影龙先拆治疗水晶，再抓停栖窗口。 |
| 召援与控场 | 育母蜘蛛、太阳鸟·乌姆武提、异教牧首、灾厄教父、凋灵死灵法师、灾厄宰相、普通／不祥死者之王、末影守望者、提洛斯 | 给主目标和援军分配火力。宰相会汲取怒鬼回血，应优先处理身边怒鬼。提洛斯的骑士和火区会共同挤压落脚空间。末影守望者有 12 格的常规伤害来源距离限制，还会拉怪吸血，带大群仆从贴身有代价。 |
| 备场与移动路线 | 血肉墙、血肉山、下界合金巨兽、利维坦 | 血肉墙要一条能连续后撤、沿途补给的长路。血肉山更需要在固定交战区留出几条横移通道，避开火柱并清附着物。锻造厂要考虑巨兽会从岩浆补给。利维坦在本实例离水免伤，应带水下呼吸和水中机动装备进场。 |
| 火力换位 | 凋灵、斯库拉、先驱者、咒翼灵骸 | 留机动能力给第二波攻击。凋灵半血后要切换对付凋灵装甲的手段。斯库拉的波浪和雷区需要连续换位。先驱者切导弹、激光和冲锋，工厂 EMP 值得提前勘察。咒翼灵骸能在空中改换武器，再用幻影戟封走位。 |
| 回复与伤害交换 | 巫婆、孤魂尸鬼、星之魔女、使徒 | 巫婆的药剂和反伤会惩罚盲目连打。孤魂尸鬼命中可抽取灵魂并自疗。星之魔女有单次限伤和受击间隔，应把输出分配到连续窗口。使徒需同时躲开可以为它回血的箭，并为半血后的第二阶段留下补给。 |

## 哪些战斗应单列

| 条目 | 建议标记 | 在流程中的处理 |
|---|---|---|
| 雕刻家·通臂大师 | 技巧试炼 | 可以第二章水平去尝试。交 1 根泥峭棒，在 400 秒内完成 60 格岩台攀登。成绩记登顶互动，战力榜不替它评分。 |
| 乌姆武提交易、霜冻巨兽偷晶 | 非击杀解法 | 面具与 7 金块可走太阳祝福交易。霜冻巨兽可偷冰晶。这两件事适合另做见闻，现有讨伐委托依旧读取击败记录。 |
| 地牢守卫、监守者 | 越界警戒／可规避威胁 | 地牢守卫的 9999 生命、攻击和护甲在提示玩家先挑战骷髅王。深暗之域适合做潜行调查；若专程讨伐监守者，可暂按Ⅴ档的个人挑战准备。 |
| 双子魔眼、毁灭者、机械骷髅王、世纪之花 | 后备首领 | 本版有实体与战斗 AI，尚未确认常规生存召唤入口。将来若接入，可分别归入双目标追击、多节切位、多臂拆解、弹幕控场，再测定档位。 |
| 敌对红石傀儡、敌对红石巨兽 | 条件遭遇 | 本实例关闭两者的袭击刷新，常规蓝图会造出仆从。战术上前者属于重击与布雷，后者属于远近火力切换。稳定敌对入口确认后再排悬赏。 |

## 会改变档位的三个条件

- **莱特兰等级。** 灾变八王的专属配置都有最低等级 200 字段。以实际吃到 200 级修正的焰魔为例，450 基础生命按当前系数会到 1800，再叠其他词条。它还有限伤、正面盾和抓取，因此放毕业档。末影龙若实际吃到 100 级修正，200 基础生命同理可达 800。再生、领主或适应等词条要随个体另看。
- **变体与维度。** 普通死者之王是 500 生命、15 护甲，不祥形态是 1000 生命、45 护甲，召唤伤害也增加。两场分别列Ⅳ、Ⅴ档。使徒在下界还有 50% 减伤和更快恢复，适合作为最后一项挑战。星之魔女默认切磋列Ⅴ档，自定义切磋按实际参数另评。提洛斯的不祥形态在本实例关闭。
- **队伍与武器。** 泰拉首领中启用多人增强的个体会按同维度人数增加生命，铁魔法两王也会按附近参战人数增加生命。噬星之刃的 48 格穿墙剑气和四阶群体爆发会显著帮助清援。首领自己的阶段无敌、格挡、距离门槛与限伤仍要逐项处理。世界吞噬怪等多部位目标的实战收益值得优先试。

世界进度继续由两场战果串起：史莱姆王开放邪恶边境，第三章血肉墙或血肉山开启困难模式。其余首领可供不同打法反复回访。第二章可以留下古代工厂坐标，第六章补给站交班以后再带下界之星回去唤醒先驱者，同一处遗址就有两次不同目的的远征。[本版属性、入口与机制图鉴](../mods/开发版首领与精英图鉴.md) · [当前主线与装备说明](campaign-field-guide.md)
