# 第一章：重启第一座工坊

状态：**已部署／待用户实测**。本章接在史莱姆王之后，沿用序章进度。它让玩家从异常地区采样，在自己的工坊掌握加工，再携带工具恢复一座野外旧工坊。正文提供玩法说明；完整剧情、人物身份与后续封印关系仍留待创作。

采样与动力建设可以并行，提前准备的材料会保留记录。任务检测不收走材料；实际合成与设备校准照常消耗配方材料。

## 三个新配方

| 设备 | 消耗 | 产出 |
|---|---|---|
| 磨石 | 乌木原木或暗影原木 ×1 | 浸染纤维 ×2 |
| 机械搅拌器＋工作盆，不加热 | 浸染纤维 ×2＋红石粉 ×1＋黏液球或汇流凝胶 ×1 | 共振胶 ×1 |
| 工作台 | 铜板 ×2＋铁板 ×2＋玻璃 ×1＋传动杆 ×1＋共振胶 ×1 | 粗制调谐器 ×1 |

调谐器工作台排列：上排“铜板／玻璃／铜板”，中排“铁板／共振胶／铁板”，下排“空／传动杆／空”。全部新配方均为确定产出。**4 原木→8 纤维→4 胶，正好用于 1 个工具和 3 次修复。** 新材料和工具不加入无限之核复制白名单。

Create 设备保留原配方。先用压机压铁板，再做搅拌头与搅拌器，起步不需要黄铜、烈焰人或下界。推荐压机与磨石使用 8 RPM 支路，搅拌器经两级齿轮增速到 32 RPM；预留两台小水车，按照实际应力显示增加动力或分组运行。普通熔炉仍可冶炼原料。

## 调谐器与现场修复

- **地图**：在主世界手持调谐器，对空气右键领取勘测图。可再次操作补领，有短暂冷却。若附近尚未找到工坊，向未探索的陆地区域前进后再试。
- **诊断**：对设备操作可查看缺少动力、转向不符或尚未校准等提示。空手操作设备也能查看状态。
- **接口**：继电器有圆孔或对应符号的彩色正面就是动力接口。将 Create 传动轴或齿轮放在正面相邻一格，轴向对准设备，再接上动力。
- **转速**：动力、传动和信号三处节点均要求至少 8 RPM；传动节点额外要求显示为正转。通过改变齿轮啮合调整方向，实际正负转速见诊断。
- **校准**：条件满足且背包有共振胶时，对准设备长按右键约 3 秒。成功才消耗 1 份胶；松开或条件失效不会完成校准。
- **启动**：三处节点必须属于同一座工坊，全部校准且保持供能后，操作该工坊中央控制台。世界共享恢复里程碑，任务奖励从 FTB 任务书领取。

调谐器任务可领取现场维修包，内含 3 台小水车、2 个水桶、传动杆、大小齿轮、扳手和 128 个圆石。出发时带上 3 份共振胶，可以给三处节点分别供能，也可以接成同一条传动线。普通建筑可以探索和改造，维修簿在中枢启动后开放。

恢复工坊后可领取效率Ⅲ／耐久Ⅱ钻石镐、安山合金、传动件、成批建材和 2 份共振胶。留 1 份胶制作第二章的遗产档案台。维修簿给出工程、奥术与远征三类调查线索，第二章从这里接续。
