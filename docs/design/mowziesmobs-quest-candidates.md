# Mowzie 生物任务候选

日期：2026-10-16。**【建议】尚未实施或定为正典。** 用户允许将新装模组的生物考虑进主线或支线；本轮只保存候选，不修改任务书、掉落、配方、战斗数值或世界阶段。第一章史莱姆王及邪恶地形开放规则保持现状。

核查对象为本地 Mowzie's Mobs 1.8.2。下表的实体资源名与中文名称来自该 JAR 的语言/实体战利品资源；结构资源包含 `wrought_chamber`、`frostmaw_spawn`、`umvuthana_grove`、`monastery`。这不代表已在用户世界发现对应结构，也不把战斗强度或生成条件视为已验证。

| 本地实体 ID / 名称 | 候选位置 | 可采用的任务方向 |
|---|---|---|
| `mowziesmobs:foliaath` / 巨噬叶 | 初期探索支线 | 认识危险植物、绕行或清除聚落附近威胁；保持可选，不要求所有玩家刷稀有掉落 |
| `mowziesmobs:ferrous_wroughtnaut` / 钢铁守护者 | 史莱姆王之后的遗迹支线 | 从遗迹线索引导到地下挑战，作为准备充分后可选的战斗节点；先做支线，再讨论是否与主线调查有关 |
| `mowziesmobs:frostmaw` / 霜冻巨兽 | 后续寒冷地区支线 | 寒地探险、准备与讨伐链；开放时点待实际战斗强度和平衡确认 |

建议先制作一条史莱姆王之后、与钢铁守护者有关的可选遗迹支线，衔接“离开聚落探索失落文明”的方向。若用户选择其他对象或希望纳入主线，再按该方向细化。具体遗迹叙事、挑战条件、奖励和解锁关系应先给出可审阅方案。

模组名称中的“守护者”不自动对应世界观中的封印守护者。是否涉及黄金时代、污染、封印或薪火，必须遵循作者设定与确认状态；不把该模组原生背景直接提升成整合包正典。

后续实施前需要确认具体任务链，并核对实体注册 ID、实际生成/寻找方式、触发条件与奖励可用性；试炼须使用其完成状态，而非仅用击杀统计。任务 ID 继续采用 FTB 可接受的正有符号 long，明确依赖与线性/可选分支关系。最终实机验收由用户执行。
