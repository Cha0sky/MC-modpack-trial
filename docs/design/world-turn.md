# 第三章 · 世界转折

在第二章使用遗产档案台领到档案书后，打开任务书上的第三章。

1. 勾选远征准备并领取金胡萝卜、抗火药水和圆石。血肉首领的原生进度会开启困难模式并转换部分主世界地形，初次验收请使用备份存档。
2. 按向导巫毒玩偶的指引，在下界召唤并击败血肉墙或血肉山中的一位。已有的首领战果可以接续。收好原生掉落的神锤。
3. 世界记录同时显示血肉首领战果和困难模式开启时，任务「世界已进入困难模式」完成。带档案书再用遗产档案台即可刷新战果、困难模式和地形转换三项状态。玩家等待转换时也可以准备采矿。
4. 用神锤破坏恶魔祭坛或猩红祭坛显现矿物。用地狱熔炉熔炼 3 份粗钴或粗钯金，取得任一种新锭即可得到经验修补书、经验瓶和地狱砖。

世界进度核心读取汇流来世 1.2.4 的原生通关记录、困难模式标志与转换状态。服务器把这些状态转为 FTB 任务记录。已完成的旧存档可在使用档案台后领取进度。仅用转换器开困难模式时，首领战果仍需挑战取得。

第二章自选挑战额外接受诡厄的骷髅领主。先驱者、焰魔和使徒留作后期战斗候选，推荐时期随装备实测再定。
