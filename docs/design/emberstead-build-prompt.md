# 余烬驿：初始聚落建筑提示词

接入方式更新（2026-10-16）：建筑源与预览不变；统一地坪版实测失败后，用户允许每栋适应不同地形高度并有限调整位置，六组件全部为必需且由道路连接，不用旧屋后备，也不允许缺件。具体落地位置/高度不保证与平地预览相同，建筑外观仍使用本提示词对应的正式 MCP 模板。

以下为本次提交的可复用建筑提示词；是初始聚落美术设计，不扩展作者世界观的既定事实。

> 为 Minecraft Java 1.21.1 的《失落世界》初始章节设计一处名为“余烬驿”的小型遗民聚落。玩家从村民收留他的家中醒来，手边仅有随身剑；家是可继续使用的起始基地。气氛温暖、朴素、略有岁月感，以可居住的小木石住宅为中心，避免宏伟城堡与规则方盒。
>
> 使用云杉木骨架、浅色灰白墙、深板岩基座和深板岩瓦坡屋顶。点缀少量锁定氧化状态的风化铜门廊屋面，给植物、花箱、窗台、百叶窗、砖烟囱和灯笼留下位置。每栋住宅至少三种立面深度：凸出的梁柱、窗台与门廊。主角住宅采用不对称 L 形侧翼，加上三格以上深度的入口门廊；不能只靠屋顶制造轮廓。坡屋顶有真实台阶、外挑屋檐和收拢的屋脊，室内至少三格净高，门窗必须真实贯通。
>
> 六块独立组件分别为：player_home（含屋檐最多15×17，红床、两只空箱、工作台、安全室内出生点）、villager_west 和 villager_east（各最多11×13，至少两张床与安全村民站位）、well（7×7）、farm（13×15，小麦/胡萝卜/灌溉）、expansion_plot（11×9，空地和简易围栏，预留基础机器，不摆放高级机器）。所有入口朝北，坐标 z=-1 的入口连接局部门廊/小径。各模块地面 y=0，所有方块 y>=0。道路由运行时连接，组件之间不要铺一整片地基。
>
> 整体预览为错落的小村落，而不是工业设施展示架。用形状操作生成墙、梁、地板、屋顶；零散方块只用于细节。纯原版方块，禁止实体、战利品 NBT、红石逻辑门、火源、危险陷阱或模组机器。箱子无物品，出生点脚下为完整地板，脚部及上方为空气。床和门必须成对导出两个部分且朝向正确。
>
> 调用建筑 MCP 的 get_build_style_guide，然后 show_structure 展示，render_structure 获取两张实际预览；按看见的问题只做必要调整，最多三轮。最后 strict=true、mc_version=1.21.1，导出 Sponge .schem 与最终操作 JSON。注意文件后缀是 .schem。输出到仓库 assets/settlement/emberstead，提供六模块 bounds、入口、床和出生点清单；Sponge 文件用于构建时转换成核心模块的原生结构模板，运行时不依赖 WorldEdit。

## 资产约定

- `assets/settlement/emberstead/generate_operations.py` 为可重复的形状操作源；执行后生成 `operations.json`、`layout.json`。
- `emberstead.schem` 是整个预览的六组件源文件；模块边界互不相交，坐标非负，农田(0,0,0)地基为归一化锚点。
- `layout.json` 的 bounds 是 `[x0,z0,width,depth]`；其余 home/bed/villagers/entry 坐标均相对所在模块。entry 的 y=0 表示入口地面，而不是实体脚部。desired 相对玩家房屋原点，只是选址偏好。
- 预览将六模块放在相同高度便于观察；游戏内每栋独立寻找地形高度，再由生成器连接道路。
- MCP预览为方块颜色/形状示意，不等同于 Minecraft 贴图或最终地形实机截图。

## 本次实际生成

- 使用建筑 MCP 的风格指南、3D viewer、实际截图与严格导出流程，最终源文件共280个形状/细节操作；尺寸43×14×40，2096个非空气方块与391个显式空气方块。
- 第一轮图中主屋长侧墙的浅色面较平，第二轮只添加一根木立柱改善分隔；保留已经成立的门廊、错落屋顶、烟囱和基座。两张最终预览为 `emberstead-preview-northwest.png`、`emberstead-preview-southeast.png`。不继续为收集证据扩大检查。
- 总村落平面接近方形、包括农田在内总用材超过五种，MCP为此给出提示；六栋分别有用途与体量区别，主屋已有实际侧翼和深门廊，未把全村误当作一栋建筑重做。
- 建筑 MCP 本机读取 JSON 的默认编码是GBK，因此操作源使用纯ASCII英文说明；中文提示词保存在本文件，以免非ASCII描述导致导出失败。
- 完整视觉评审与导出统计见资产目录的 `build-report.json`。没有启动游戏。
