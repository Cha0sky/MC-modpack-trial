# 机械动力与无限之核：资源及科技推进规划

确认日期：2026-10-16（Asia/Shanghai）。状态：**用户已确认设计方向，待后续相关任务实施**。本次仅保存规划，不改代码、配方、任务或实例，不代表功能已经生效，也不自动授权下一项开发。

## 已确定的方向

机械动力承担失落文明复苏前期的必要科技路线。部分主线关键道具依赖机械动力专属工艺或部件，使玩家需要建立实际可用的小工坊；喜爱建设的玩家可以继续扩展产线、物流、工厂和建筑。主线需要的工艺能力与可选的工厂规模分开，不要求所有玩家建设大型工厂。

资源与加工的分工为：**探索获得样本 → 无限之核供应允许的基础原料 → 普通设备或机械动力加工 → 制造关键道具 → 继续探索和技术发展**。

| 内容 | 已确定规则 |
|---|---|
| 泥土、木材、普通石材、煤炭、原矿 | 可纳入无限之核生产范围；使用明确物品白名单，不无限扩大类别 |
| 金属锭、合金、机械零件、机器及其他加工成品 | 不允许无限之核直接复制，保留实际加工需求 |
| 普通熔炉 | 照常保留，不为强迫机械化而删除普通熔炼路线 |
| 机械动力 | 以更高加工效率、批量处理和自动化形成生产优势；具体速度与吞吐量后续平衡，不宣称目前所有机械加工都已更快 |
| 部分主线关键道具 | 需要机械动力专属加工或专属部件，构成前期科技的必要节点 |
| 后续科技模组 | 可在加入并获确认后承接进阶加工；本规划不授权安装新模组 |
| 生成器等级 | 影响生产效率，不因等级名称而自动允许生产对应金属锭、宝石或加工成品 |

现有第一章的泥土生成器目标可保留，不因本次限制而删除泥土或木材生产。普通熔炉保留基础冶炼入口，避免启动机械动力之前缺少必要材料。

## 后续实施时必须处理的边界

- 复制规则同时覆盖模板制作和机器实际产出，包含未定制模板的默认产物、已有定制模板及自动化输入，不能只限制新模板配方。
- 当前代码仍有按等级默认产出木头、泥土、铜锭、铁锭、金锭、钻石及下界合金锭的行为；这些是现状，不代表都符合新规划。后续需将默认产物纳入同一白名单规则。
- 不因规则收紧直接删除旧模板或库存；不合规模板的停产提示及兼容处理在实际任务中落实。不得自动改写用户存档。
- 高阶资源与世界阶段协调；获得模板不能绕过资源的阶段限制。具体阶段绑定尚未实施。
- 检查关键物品的其他配方、掉落、交易及战利品来源，确保指定工艺确实有必要；不为此封锁日常生活和普通建筑材料。
- 设备及部件配方需要明确起步顺序，避免关键装置与它的制造设备互为前置。
