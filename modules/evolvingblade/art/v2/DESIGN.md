# 噬星之刃第二版美术设计

绘制/验收：Codex；工程接入/特效代码：DSH。新贴图由 imagegen 重绘，每阶段单独生成，原1.0贴图保留在基线源码包。母版 masters/stage0.png 至 stage7.png 将陆续到齐；资产导出后保持透明度、完整轮廓和游戏小图可读性，不用生成大图直接塞进物品图集。

统一方向：平面像素剑，剑柄左下、剑尖右上，黑曜石/暗钢结构、银青刃光、紫金星核；克制的亮暗分区，先轮廓后符文，不使用背景、影子、文字或大面积外部烟雾。

| 阶段 | 轮廓与色彩 |
|---|---|
| 0 胚刃 | 暗钢细刃、朴素银护手、小紫晶，低亮度 |
| 1 初醒 | 护手向上收拢、菱形剑肩、下段初生紫光 |
| 2 灵锋 | 银青细刃线、三点星纹、双银箍剑柄 |
| 3 饮魂 | 紫红深槽、钩形护手、灵魂晶核，轮廓轻微分层 |
| 4 裂空 | 清晰双层银青裂隙、角形悬空状护手、紫色空间核 |
| 5 弑王 | 黑金结构、紫金冠状护手，银刃切边 |
| 6 星灾 | 黑曜石主体、青白星云槽、银紫多层护手与高亮星核 |
| 7 终焉 | 青白外刃、暗紫核心、金银冠状护手，少量清晰星轨镂纹 |

特效风格：剑气为沿视线前进的纤细青白弯月，有紫色内缘和短拖尾；爆发为从玩家躯干扩张的透明三维球壳，以不同倾角的稀疏星轨描边；命中是紧凑交叉星芒，吸血是极少数紫色点向玩家汇聚。终阶加强弧线层次而非屏幕填充。无刺眼满屏FLASH、地面SWEEP圆环或爆炸地形影响。

DSH需做资产导出工具，将母版适配64或128 RGBA、硬边轮廓，再在小尺寸和第一人称里核验；输出接触表用于独立验收。导出不重新设计或廉价换色，所有八张母版内容均由Codex独立绘制。
