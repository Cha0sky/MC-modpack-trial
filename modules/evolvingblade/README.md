# 噬星之刃 / Evolving Blade

NeoForge 1.21.1（NeoForge 21.1.248）模组：一把**不可破坏、抗火**的成长之剑。
击杀敌对生物与 Boss 累积成长点，选择一条修行路线后沿 8 个阶段成长；所有门槛与数值都由**服务器配置**决定，
成长数据按玩家、按存档独立持久化，客户端只负责显示服务器下发的权威数值。

> 模组 ID：`evolvingblade`　｜　物品 ID：`evolvingblade:star_eater`　｜　服务端与客户端都需要安装。

---

## 1. 操作方式

| 操作 | 说明 |
|---|---|
| 右键（主手持剑） | 阶段 2+ 释放**剑气**（直线飞行、撞墙即停） |
| Shift + 右键 | 阶段 4+ 释放**裂空爆发**（以自身为中心的范围伤害） |
| 满蓄力主手近战命中 | 阶段 3+ **吸血**；阶段 5+ 对 Boss 追加**斩 Boss 加成**；阶段 1+ 用本剑击杀**回血** |
| `G` 键（可改键） | 未选路线时打开三选一界面；已选路线时打开成长仪表盘 |
| 首次进入游戏 | 自动弹出一次三选一界面（每次登录最多一次；关闭后不再自动弹出） |

三选一流程：**点击卡片 → 点击「确认选择」→ 第二次确认界面明确提示"永久锁定" → 确认后才生效**。
选择一旦提交**不可更改**（管理员可用命令强制改）。

## 2. 修行路线（模式）与八阶段

| 阶段 | 名称 | 总基础攻击 | 总攻击速度 |
|---|---|---|---|
| 0 | 胚刃 | 7 | 1.6 |
| 1 | 初醒 | 12 | 1.7 |
| 2 | 灵锋 | 24 | 1.8 |
| 3 | 饮魂 | 48 | 1.9 |
| 4 | 裂空 | 120 | 2.0 |
| 5 | 弑王 | 300 | 2.1 |
| 6 | 星灾 | 750 | 2.2 |
| 7 | 终焉 | 1500 | 2.4 |

升阶需要**同时**满足成长点与 Boss 击杀两个门槛。三个模式只有门槛不同，**终局强度完全一致**：

| 模式 | 成长点门槛（阶段 0→7） | Boss 门槛（阶段 0→7） |
|---|---|---|
| 快速 quick | 0 / 10 / 30 / 70 / 140 / 240 / 400 / 600 | 0 / 0 / 0 / 1 / 1 / 2 / 3 / 5 |
| 标准 standard | 0 / 50 / 150 / 350 / 700 / 1200 / 2000 / 3000 | 0 / 0 / 0 / 1 / 3 / 6 / 12 / 20 |
| 长期 long | 0 / 300 / 1000 / 2400 / 4800 / 8000 / 13000 / 20000 | 0 / 0 / 0 / 5 / 15 / 30 / 60 / 100 |

成长点权重默认：普通敌对击杀 **1** 点，Boss 击杀 **100** 点（可在配置修改）。

## 3. 能力数值（默认值，全部可在配置修改）

| 能力 | 解锁 | 数值 |
|---|---|---|
| 击杀回血 | 阶段 1 | 每次用本剑击杀回复 **2** 点生命 |
| 剑气 | 阶段 2 | 伤害 = **100%** 本阶段基础攻击；射程 **24** 格；冷却 **8 秒**（终阶 **4 秒**）；最多命中 **3** 个目标；穿墙？**不穿**，撞墙即停 |
| 吸血 | 阶段 3 | 满蓄力近战回复**实际生命损失**的 **5%**（单次上限 4）；阶段 6+ 为 **10%**（上限 8） |
| 裂空爆发 | 阶段 4 | 伤害 = **150%** 本阶段基础攻击；半径 **6** 格（终阶 **8**）；冷却 **20 秒**（终阶 **10 秒**）；最多 **32** 个可见目标；不破坏方块 |
| 斩 Boss 加成 | 阶段 5 | 追加目标**最大生命**的 **1%**（上限 200）；终阶 **3%**（上限 1000）；同一玩家对同一目标 **20 tick** 只能触发一次 |

流血/爆发等技能伤害**不触发吸血**，也不触发斩 Boss 加成（防递归）。

### 3.1 数值口径与结算语义（重要）

- **表里的"总基础攻击/总攻击速度"已经包含玩家自身的 1 点基础攻击**（例如阶段 0 是"玩家 1.0 + 剑 +6.0 = 7"）。
  界面与 tooltip 显示的就是这个总值，不会再多加 1。
- 阶段差异以**持有者**身上的临时修饰符施加：同一把剑在阶段 7 的持有者手上是 1500 / 2.4，
  交给阶段 0 的持有者立刻变成 7 / 1.6；物品上伪造的阶段组件**不会**改变强度。
- 只移除本模组自己的修饰符 id，原版基线与第三方模组修饰符都保留（第三方加成叠加在阶段总值之上）。
- **技能额外伤害**（斩 Boss 加成）只绕过**护甲**与受击冷却：仍然遵守无敌、抗性、模组事件取消；
  不会直接 `setHealth`/`kill`，也不会递归触发自身。
- 数据按**玩家 + 存档（世界）**独立保存；冷却写入的是绝对到期 tick（换维度、重生、重连都不能重置）。
- 成长点/击杀计数是**饱和计数**（不会为负、不会溢出），普通敌对与 Boss **不重复计数**：
  一次击杀要么按 Boss 记（配置权重点数），要么按普通敌对记，绝不两者都记。
- 升级需要**成长点与 Boss 击杀两个门槛同时满足**；三种模式只是门槛不同，**终阶强度完全一致**。

## 4. 合成配方与获取

- **合成**（无序合成）：铁剑 ×1 + 铁锭 ×2 + 紫水晶碎片 ×1 + 红石 ×1 → 噬星之刃 ×1。
- **首次选择路线后赠送**：每名玩家每个存档最多**成功**获得一把（背包满时保持"待发放"，腾出主背包空位后自动送达，不掉落、不重复）。
- 创造模式物品栏也有（「噬星之刃」页签）。
- **后期安装不追溯历史击杀**：本模组只统计安装之后的击杀，初始计数为 0。

## 5. 配置位置

所有门槛/数值都是**服务器配置**（`ModConfig.Type.SERVER`）。NeoForge 21.1 的实际行为（已用本工程自己的运行目录核对）：
**配置文件始终在实例/服务器根目录的 `config/` 下**，单人客户端也一样；世界目录里的 `serverconfig/`
只是可选的"按世界覆盖"位置（NeoForge 会在那里放一份 `readme.txt` 说明）。

| 专用服务器 | `<服务器根目录>/config/evolvingblade-server.toml` |
| 想只对某个世界覆盖 | 把该文件复制到 `<世界目录>/serverconfig/evolvingblade-server.toml` 再修改 |

`run/world/serverconfig/`、`run-isolated-client/saves/<世界>/serverconfig/` 里**只有 NeoForge 的 `readme.txt`**。

## 6. 管理员命令

需要权限等级 2（OP）：

```
/evolvingblade info [玩家]                        查看模式、阶段、计数、下一阶条件（不带参数时看自己）
/evolvingblade mode <玩家> <quick|standard|long>  强制设定模式（保留计数与赠剑标记）
/evolvingblade set <玩家> <敌对击杀数> <Boss击杀数> 重设计数并按当前权重重算成长点
/evolvingblade bosscheck <实体>                   查询该实体为什么被判定为 Boss/非 Boss（含拒绝原因）
```

`bosscheck` 是排查兼容性的第一手段：它会打印命中的规则（配置包含/排除、标签、ServerBossEvent 字段、
类名包含 Boss、自动探测生命阈值……）。

## 7. 兼容性与判定规则

- **敌对判定**：默认按原版敌对生物（`Monster` 等）判定，可用配置的"额外敌对名单/排除名单"覆盖，
  也支持 `evolvingblade:hostile` 实体类型标签。名单与标签判定**不使用生命阈值**。
- **Boss 判定优先级**（自上而下，先命中先决定）：
  1. **配置强制排除**（最高优先级，命中即判为普通，后面所有规则都不再看）；
  2. 配置强制包含（命中即判为 Boss，**不看生命值**）；
  3. `evolvingblade:bosses` / `c:bosses` 实体类型标签（命中即判为 Boss，**不看生命值**）；
  4. **自动探测**（默认开启，阈值默认 200）——这一条是 **AND 关系**，必须**同时**满足：
     - 最大生命 **≥ 阈值（含等于）**，**并且**
     - 实体持有**非空** `ServerBossEvent` 字段（含子类字段、继承字段），**或**继承链类名包含 `Boss`。

    也就是说：**只有高血量、没有 boss 条、类名也不含 Boss 的实体不会被判成 Boss**（例如监守者 Warden
     有 500 生命，默认仍是普通敌对）。阈值可在配置里调整；把阈值调到 0 也仍然要求"bar 或类名"这一支成立。
- 末影龙、凋灵开箱即用（命中标签/bar 规则）。想把某个实体强制判成 Boss，用配置的"强制包含名单"，
  不需要依赖生命值。
- **第三方 Boss 模组**：只要它们使用标准 `ServerBossEvent`/标签/类名约定，**机制上就能被识别**；
  但本次交付**没有实际安装任何第三方 Boss 模组验证**（诚实说明，见 §9）。
- 剑气/爆发只命中敌对与 Boss，**排除玩家、友军、一切被驯服或有主人的生物**（包括别人的宠物）。
- 多部位实体（例如原版末影龙的头/身）：攻击 part 会被归一化到**父实体**结算，因此吸血、斩 Boss 加成
  与剑来源（击杀回血）都按父实体计算；父实体只被命中一次。
- 本模组不改动其它模组的属性修饰符，只移除自己的修饰符 id；卸下剑后第三方增益保留。
- 排查某一具体实体为什么被判成/没被判成 Boss，用 `/evolvingblade bosscheck <实体>`，例如：
  `/evolvingblade bosscheck @e[type=minecraft:wither,limit=1]`（会打印命中的规则与拒绝原因）。

## 8. 从源码构建（Windows 中文路径）

环境：JDK 21（`JAVA_HOME` 指向 JDK，而不是 JRE）、Gradle 使用工程内 wrapper。

```powershell
$env:JAVA_HOME = "<你的 JDK 21 路径>"
.\gradlew.bat clean build          # 编译 + 打包 + 单元测试
.\gradlew.bat ebTest               # 只跑 JUnit 5 套件
.\gradlew.bat runGameTestServer    # 无头 GameTest（需要先 cleanGameTestWorld 时见下）
.\gradlew.bat cleanGameTestWorld   # 清掉 dev GameTest 世界，保证全新世界
```

**中文/非 ASCII 工程路径的已知问题与处理**：Gradle worker 会把 classpath 写进 UTF-8 的 `@argfile`，
而 Windows JVM 按 ANSI 代码页解析，导致 `ClassNotFoundException: worker.org.gradle.process.internal.worker.GradleWorkerMain`。
本工程通过在 `build.gradle` 里用 `JavaExec`（`ebTest` 任务，classpath 内联在命令行、不使用 argfile）
运行 JUnit，并设置 `org.gradle.vfs.watch=false` 规避，**不需要修改操作系统设置**。

构建产物：`build/libs/evolvingblade-1.1.0.jar`（测试源码与 GameTest 位于独立的 `src/gametest` 源集，**不会**进入发布 jar；
发布 jar 已用 ZipFile 扫描确认没有任何 GameTest 类、`.nbt` 夹具或 dev-only 实体夹具）。

逐条验收要求到测试方法的对照见 **`docs/TEST-MAPPING.md`**（1.0.0 基线）
与 **`docs/TEST-MAPPING-1.1.0.md`**（1.1.0 增量）。

## 8.5 1.1.0 变更摘要（完整说明见 `docs/CHANGELOG-1.1.0.md`）

1. **第三方加伤分两条路径处理**：
   - 玩家属性上的阶段差值改为**纯代数差** `stageAttackDamage(stage) − stageAttackDamage(0)`；
     不再减属性 base、不再减任何第三方 `ADD_VALUE`，因此别人的 flat / 百分比加伤、
     甚至对保留 id `minecraft:base_attack_damage` 的合法改动都**被完整保留**；
   - 本模组**永不写入**保留槽位，只在它**确实缺席**（装备 tick 还没跑）时用本剑阶段 0 的
     静态基线补偿一次，原版挂上后立刻撤销；
   - 面板/提示框分开显示「阶段基础攻击」（配置口径）与「当前持剑有效攻击」（服务器属性最终值），
     未持剑时不下发有效值（不借用别的武器加成）。
2. **剑气/爆发按持有者服务端有效 ATTACK_DAMAGE 取值**（`min(系数 × 阶段基础, 系数 × 有效攻击)`），
   配置开关 `abilities.ability_damage_from_attack`（默认 `true`）。
3. **爆发改三维球判定**：球心＝躯干中心，三轴最近点距离平方 `<= r²`，贴边大型包围盒可命中。
4. **视觉重做**：客户端用连续几何画三维球壳 / 弯月刀光 / 命中星芒 / 斩痕 / 吸血轨迹，
   每帧顶点硬预算 8192、同屏效果 ≤ 12、寿命有界；施法事件走**有界网络包**，
   只为已协商该频道的连接发送。

## 10. 给复验者的开发客户端

