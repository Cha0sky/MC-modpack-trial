# MANUAL-QA-V3 —— 噬星之刃 1.1.0 材质与特效 人工验收手册

> 适用：Minecraft 1.21.1 + NeoForge 21.1.248，模组 `evolvingblade-1.1.0`。
> **请用一个全新的测试世界**（创造模式、允许作弊）。本文所有视觉结论都需要你实际看到才算，
> DSH 没有运行客户端、没有做过视觉验收。
>
> 本文只列**真实存在的命令**。模组命令只有四个：
> `/evolvingblade info [玩家]`、`/evolvingblade mode <玩家> <模式>`、
> `/evolvingblade set <玩家> <普通击杀数> <Boss击杀数>`、`/evolvingblade bosscheck <实体>`。
> **没有**"设置阶段"的命令——阶段由玩家的成长数据推导，同一把剑跟着持有者变。

## 0. 准备

```
/gamemode creative
/give @s evolvingblade:star_eater
/evolvingblade mode @s quick
/evolvingblade info
```

`info` 会显示当前模式 / 阶段 / 成长点 / 击杀数。**阶段绑定玩家，不绑定物品**：
整场测试只用**这一把剑**，反复切换阶段即可，不要给八把剑分别保留不同强度。

### 快捷模式（quick）的八阶段精确对照表

成长点 = **普通击杀 × 1 + Boss 击杀 × 100**；**两个门槛必须同时满足**。

| 目标阶段 | `/evolvingblade set @s <普通> <Boss>` | 成长点 | 说明 |
|---|---|---|---|
| 0 | `/evolvingblade set @s 0 0` | 0 | |
| 1 | `/evolvingblade set @s 10 0` | 10 | |
| 2 | `/evolvingblade set @s 30 0` | 30 | |
| 3 | `/evolvingblade set @s 0 1` | 100 | 1 个 Boss 就够门槛；下一阶段要 140 点 |
| 4 | `/evolvingblade set @s 40 1` | 140 | |
| 5 | `/evolvingblade set @s 40 2` | 240 | |
| 6 | `/evolvingblade set @s 100 3` | 400 | |
| 7 | `/evolvingblade set @s 100 5` | 600 | 终阶 |

> 注意第 3 行：`set @s 0 1` 的成长点是 100，**仍然停在阶段 3**（下一阶段需要 140 点），
> 所以"只刷 Boss 数"并不能一路升阶，两个门槛都要满足。

每次 `set` 之后用 `/evolvingblade info` 确认阶段，再看手上的剑。

## 1. 32px 八阶段材质：静态轮廓 + 缓慢材质

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1.1 | 阶段 0，手持剑看第一人称 | **32×32 逻辑像素**的简洁像素风：短直护手、普通握柄、**2–3px 宽剑身**；没有王冠 / 镂空 / 珠宝 / 复杂分叉 |
| 1.2 | 按 §0 表格从阶段 0 走到 7，每一次都看剑 | 八阶段**轮廓相同**，区别在**剑身材质**（越后期越暗靛星砂 + 银青切刃），**不是越变越大越复杂** |
| 1.3 | 阶段 0 与阶段 1 静止观察 10 秒 | **完全静止**（这两阶段是静态贴图） |
| 1.4 | 阶段 2 起静止观察 10 秒，再看阶段 5–7 | 只有**剑身内部**在极缓慢流动；**边缘 / 轮廓 / 护手 / 握柄逐帧不动**；亮点**最多 3 个、每个 1 像素**、沿剑身缓慢移动；**不出现大面积白色补丁、不闪、不彩虹** |
| 1.5 | 打开物品栏看图标；把剑丢到地上看掉落物 | 三个尺度都能认出同一把剑，不糊、不出现透明空洞 |

> 若看到暗剑身上**成片发白**、或轮廓在抖，就是不合格。

## 2. 剑气（横切射线的短弧刃）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 2.1 | 站平地，朝前方空气右键 | 出现**一条清楚的短弧刃**（宽约 1.4 格），**正对镜头**，从**近处**（约 0.7 格）沿视线飞到射程末端，后面只有**极短**尾迹；不是侧面扁带、不是团圆盘 |
| 2.2 | 朝 3 格外的僵尸右键 | 服务器立即结算目标伤害；弧刃用于表现。伤害在**施法那一刻**由服务器射线结算，不要期待"飞到才掉血" |
| 2.3 | 僵尸放 1 格厚石墙后，右键 | 弧刃在**墙面处终止**，墙后僵尸**不掉血** |
| 2.4 | 对着正方形房间的对角右键 | 弧刃沿视线走直线，不沿地面、不成圆环 |

**冷却**：剑气 8 秒（阶段 2–6）/ 4 秒（终阶）。测下一条前先等冷却结束，按 G 打开成长面板查看剩余冷却。

## 3. 范围爆发（三维球：上 / 下 / 斜向 + 墙）

> 半径：普通阶段 **6 格**、终阶 **8 格**。判据是**目标包围盒到球心（你的躯干中心）的最近点**。
> **请在创造飞行中悬空测试**，不要站在实体石台上期待"穿过平台命中"。

召唤与清理（每次只留需要的那几只）：

```
/summon minecraft:husk ~ ~4 ~ {NoAI:1b,NoGravity:1b,Tags:["ebqa_up"]}
/summon minecraft:husk ~ ~-4 ~ {NoAI:1b,NoGravity:1b,Tags:["ebqa_down"]}
/summon minecraft:husk ~3 ~3 ~3 {NoAI:1b,NoGravity:1b,Tags:["ebqa_diag"]}
/summon minecraft:husk ~8 ~8 ~8 {NoAI:1b,NoGravity:1b,Tags:["ebqa_diag_out"]}
/kill @e[tag=ebqa_up]
/kill @e[tag=ebqa_down]
/kill @e[tag=ebqa_diag]
/kill @e[tag=ebqa_diag_out]
```

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.1 正上方 | 悬空，`ebqa_up` 召唤在**正上方 4 格**，潜行 + 右键 | **命中**（球有上方覆盖，不是地面圆环） |
| 3.2 正下方 | `ebqa_down` 在**正下方 4 格**，潜行 + 右键 | **命中**（下方覆盖） |
| 3.3 斜向内 | `ebqa_diag`（水平 3 + 垂直 3 ≈ 4.2 格），潜行 + 右键 | **命中** |
| 3.4 斜向超界 | `ebqa_diag_out`（**水平 8 且垂直 8**，直线距离 ≈ 13.9 格，包围盒整体也在 8 格之外），潜行 + 右键 | **不命中**（确保连包围盒最近点都在球外） |
| 3.5 墙后 | 在你自己与僵尸之间放 1 格厚石墙，僵尸贴墙后 1 格，潜行 + 右键 | **不命中** |
| 3.6 墙后对照 | 同一位置放两只：一只墙后、一只无遮挡（用 `/clone` 或手动摆），潜行 + 右键 | **只有无遮挡那只**掉血（证明是墙挡的，不是范围没到） |
| 3.7 视觉 | 空旷处潜行 + 右键 | 一次约 14 tick（0.7 秒）的**安静稀疏脉冲**：三条**不同平面、不同方位**的分段弧，半径就是 6 / 8；**弧线上下都有**；**不旋转**、不是实心球、不是地面圆圈、不挡视线 |
| 3.8（可选，较难） | cap 32：终阶时在脚边 3 格内挤 36 只 NoAI husk，爆发一次 | 最多 32 只掉血；需要能看血条才能逐一核对，看不清就跳过这条 |

**冷却**：爆发 20 秒（阶段 4–6）/ 10 秒（终阶）。逐条隔离测试，别连着放。

## 5. 面板：阶段基础攻击 vs 当前持剑有效攻击

| 步骤 | 操作 | 预期 |
|---|---|---|
| 5.1 | 手持剑按 **G** | 分两行显示**「阶段基础攻击」（配置口径）**与**「当前持剑有效攻击」（服务器属性最终值）**，并有说明 |
| 5.2 | 把剑放回背包（空手或拿别的武器）再看 | 显示**「未持剑」**，不借用另一把武器的数值 |
| 5.3 | 给自己加标准属性加成（读实际 1.21.1 命令源码：属性 id 是 `minecraft:generic.attack_damage`，操作名是 `add_value`） | 见下 |
| 5.4 | 加完再放剑气 / 爆发 | 技能伤害跟着变大（剑气 ×1.0、爆发 ×1.5） |
| 5.5 | 把窗口缩到 854×480 及更小 | 面板长句自动换行，不越界、不重叠 |

5.3 的具体命令（测完记得移除，避免影响后续步骤）：

```
/attribute @s minecraft:generic.attack_damage modifier add ebqa:bonus 13 add_value
/evolvingblade info
/attribute @s minecraft:generic.attack_damage modifier remove ebqa:bonus
```

想看乘法口径可以再加一条 `add_multiplied_total`：

```
/attribute @s minecraft:generic.attack_damage modifier add ebqa:mult 0.5 add_multiplied_total
/attribute @s minecraft:generic.attack_damage modifier remove ebqa:mult
```

**重要**：面板上的「有效攻击」是**属性表上的攻击力**，它**包含**标准属性加成，
**不包含**攻击事件里的最终伤害修正。它**不是**伤害预测：暴击、附魔（锋利等）、
目标护甲 / 抗性 / 吸收、受击冷却、以及被取消的伤害事件都会继续影响实际掉血。
请不要把面板数字当成"这一刀一定打这么多"。

## 6. 共存与保护

| 步骤 | 操作 | 预期 |
|---|---|---|
| 6.1 | 装第三方加伤模组（如 rpgleveling 的加点） | 近战与技能都受益；模组自己的属性行不受影响 |
| 6.2 | 用骨头驯服一只狼（`/give @s bone` 后右键）带在身边，再放爆发 | 狼**不掉血**（所有被驯服生物都排除） |
| 6.3 | 与另一名玩家同队（`/team add t` + `/team join t <玩家>`）后放爆发 | 队友**不掉血** |
| 6.4 | 换别的武器再换回剑 | 技能冷却**不重置**（冷却按玩家记） |
